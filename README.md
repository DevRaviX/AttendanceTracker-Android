# Attendance Tracker (Premium)

A beautifully designed, highly efficient college attendance tracking app built natively for Android using Jetpack Compose and Material Design 3.

## Features
- **Dynamic 75% Rule Engine:** The app does the math for you. It tells you exactly how many classes you must attend to hit 75%, or how many you can safely bunk without dropping below the threshold.
- **Progressive Onboarding:** Pre-loaded with specific university timetables based on semester and lab groups.
- **Interactive Calendar:** A custom-built Jetpack Compose calendar view. Tap any day to log attendance (Present, Absent, Mass Bunk, Cancelled, Holiday) or edit past records.
- **"Today's Schedule" Dashboard:** Instantly see what classes you have today with quick-action logging buttons and a beautiful glassmorphic progress ring.
- **Offline First:** Powered by Room Database for instant, lag-free performance. No internet required.

## Tech Stack
- **UI Framework:** Jetpack Compose (Material Design 3)
- **Language:** Kotlin
- **Architecture:** MVVM (Model-View-ViewModel) + Clean Architecture principles
- **Local Database:** Room
- **State Management:** Kotlin Coroutines & StateFlow
- **Navigation:** Navigation Compose
- **Preferences:** Jetpack DataStore
